# Personal Portfolio Wesbite

The code for me personal website, where I share some of my current coding projects, writing, etc..

View the live website at <https://huntercbuxton.com>.

## Tech Stack

- Node.js (v20+)
- React.js
- React Router
- react-uuid
- fortawesome
- JSON for local storage
- vite for building and testing
- eslint for linting

## Quick Start

### installation

```bash
git fetch
git checkout <branch name>
npm ci
npm run test
npm run build
```
